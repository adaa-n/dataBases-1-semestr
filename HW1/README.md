# Система учёта животных в приюте

## Описание проекта

Данная база данных предназначена для учёта животных, находящихся в приютах, а также для организации работы волонтёров и обработки заявок на усыновление.

Система позволяет хранить информацию о приютах и животных, отслеживать смены волонтёров и регистрировать посетителей, которые хотят взять животное. Отдельная сущность заявок на усыновление позволяет связать посетителей с животными и хранить информацию о статусе заявки.

## Сущности

В базе данных используются следующие сущности:

1. **Shelters** — информация о приютах.
2. **Animals** — информация о животных, находящихся в приютах.
3. **Volunteers** — информация о волонтёрах.
4. **Shifts** — информация о рабочих сменах волонтёров.
5. **Visitors** — информация о посетителях, заинтересованных в усыновлении животных.
6. **AdoptionApplications** — заявки посетителей на усыновление животных.
