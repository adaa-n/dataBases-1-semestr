# Описание проекта
Данный проект представляет собой базу данных для учёта домашних животных в приюте. Система позволяет хранить информацию о животных, их возрасте, породе, состоянии и истории пребывания в приюте.
Также база данных предназначена для учёта волонтёров, их смен и обязанностей, а также потенциальных хозяев и их заявок на усыновление животных. Это позволяет организовать работу приюта, отслеживать участие волонтёров и контролировать процесс поиска новых хозяев для животных.
Основные сущности
В базе данных планируется использовать следующие сущности:
* Animals — животные, находящиеся в приюте или на передержке;
* Volunteers — волонтёры, помогающие приюту;
* Visitors — потенциальные хозяева и посетители приюта;
* AdoptionApplications — заявки на усыновление животных;
* Shifts — записи волонтёров на смены;
* Shelters — приюты или места временной передержки.

# Основная задача
  База данных должна обеспечить удобное хранение и обработку информации о животных, волонтёрах и потенциальных хозяевах, а также позволить отслеживать заявки на усыновление и участие волонтёров в работе приюта.
